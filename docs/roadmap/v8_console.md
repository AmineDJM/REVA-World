# REVA V8 — the console: one fast interface for the whole sourced world

Owner request (2026-10-17): be far more ambitious for REVA, with an extremely efficient and useful interface.

Today REVA has three UI generations side by side (V1 screens, `/v3/*`, the V5 decision screen) over ~20 API
route groups. The data is deep (≈100 M atlas values, millions of KG statements, ≈65 k causal claims, 301 effect
estimates, thousands of sealed forecasts) but reaching it takes many clicks and knowing where to look.

V8 is **one console** at `/v8`: keyboard-first, every object one keystroke away, every number with its source on
hover, every page answering "what do we know, what is missing, what happens next, how sure are we". The
constitution is unchanged: no fabricated values, typed Missing shown as such (hatched, never 0), provenance and
licence per value, causation only as attributed claims, predictions labelled by their judged status.

## Design principles

1. **Search is the front door.** Ctrl/Cmd-K palette over entities of every kind, atlas series, countries/regions,
   forecasts, decisions, effects, sources. Results in < 150 ms warm (server index), grouped, keyboard navigation.
2. **One URL per state.** Every view (entity, map + period + indicator, comparison, decision scenario, board) is
   a shareable URL; back/forward works.
3. **Answer first, then evidence.** Each page leads with the answer (a number, a sentence, a chart) and puts the
   sources, method and caveats one click (or hover) away — never hidden, never in the way.
4. **Honesty is visible.** Badges: observed / projection / estimate / scenario non validé / prévision jugée
   (with its score vs the official forecaster). Missing cells are hatched with the reason. Licences shown.
5. **Fast.** Code-split per feature, virtualised lists, one bundle call per page (`/v1/v8/*`), cached; Lighthouse
   performance ≥ 90 on the built UI; no layout shift; works on a phone (16 px gutters, no horizontal scroll).
6. **French UI, English code.** Dark and light themes from tokens.

## Features (each one folder `ui/src/v8/features/<id>/`, contract `ui/src/v8/contract.ts`)

| Feature | Route | What it gives |
|---|---|---|
| Accueil | `/v8` | world pulse: what changed today (new data, resolved forecasts, new events), owner decisions waiting, pinned boards |
| Recherche (palette) | Ctrl-K | universal search + commands ("comparer FRA DEU inflation", "aller à pétrole brut") |
| Fiche | `/v8/fiche/:kind/:id` | universal entity page for any kind: key facts with provenance, relations by family, series sparklines, map, timeline, causal claims in/out with grades, effect estimates, forecasts about it, what is missing |
| Monde | `/v8/monde` | space-time explorer: any atlas indicator, ADM0/ADM1, time slider + animation, compare two indicators (bivariate), Missing hatched, click → Fiche |
| Comparer | `/v8/comparer` | N entities × M indicators: aligned series, tables, ranks, with vintages |
| Liens | `/v8/liens` | path finder between any two entities over relation families + causal claims; explanation of each hop |
| Demander | `/v8/demander` | natural-language Q&A (NLQA) with cited answer, chart, "how computed", follow-ups; brainstorm mode ("what is missing to predict X?") |
| Décision | `/v8/decision` | decision studio: compose a decision, propagation graph with each hop's attributed effect, fan charts, scenario comparison, sensitivity (tornado), export |
| Scores | `/v8/scores` | the honest scoreboard: every REVA track vs every official forecaster (IMF, SPF, EIA, CDC, ViEWS, …), wins AND losses, Holm, as-of, reliability diagrams, calendar of pending resolutions |
| Tableaux | `/v8/tableaux` | personal boards: pin any series/entity/forecast; watchlists with change alerts (new data, revisions, resolutions) |
| Couverture | `/v8/couverture` | what is loaded and missing per domain × country × period; queued loads; owner decisions (licences, keys, accounts) as an actionable list |
| Dossier | `/v8/dossier` | one-click brief (country, commodity, disease, decision) exported as Markdown/PDF with every citation |

## Backend (V8API and feature agents)

- New route modules only as `src/reva/api/routes/v8_<name>.py` exposing `router` (auto-included by `app.py`).
- Paths under `/v1/v8/...`. Read-only on the dev DB unless the brief says otherwise. No migration except
  `0020_v8_*` owned by V8API (workspaces/boards/watchlists) if it is truly needed.
- `contracts/openapi.json` regenerated by whoever adds routes (append-only diff; `npm run gen:types`).

## Agents (wave V8)

V8SHELL (shell, palette, router, design tokens, nav, theming, perf budget), V8API (search index, entity bundle,
change feed, boards persistence), V8FICHE, V8MONDE (+Comparer), V8LIENS, V8ASK, V8DECISION, V8SCORES,
V8BOARDS (Tableaux + Accueil feed), V8COUVERTURE, V8DOSSIER, then V8QA (end-to-end Playwright, accessibility,
