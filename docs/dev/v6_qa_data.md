# V6 QA-DATA — permanent, automated data-quality checks (`reva qa run`)

Agent QA-DATA, 2026-10-17. Goal: quality checks that run on every load, scale with volume, and only **report**
(nothing is fixed, retracted, blended or rewritten). Method follows `review_v4_v5_audit.md` (independent
re-implementation, provenance down to the raw bytes through the store API), but as code + tests instead of a one-off
audit. Latest results: `docs/dev/qa_report_latest.md` (generated by the command below on the dev DB).

## 1. What was built

| file | role |
|---|---|
| `src/reva/qa/backend.py` | read-only data access: Postgres (connection with `default_transaction_read_only = on`, every statement in a READ ONLY transaction) or fixture mode (in-memory DuckDB with the same `kg.…`/`meta.…`/`evidence.…` names + `MemoryStore`); objects only through the store API (`get`/`head`/`open`, zstd-wrapped objects decoded transparently and re-hashed); SQL literals validated + inlined (`lit`), no Postgres-only syntax |
| `src/reva/qa/atlas_checks.py` | one pass over the latest live version of every atlas table (Parquet through the store): units, time, provenance and licence per table; collects the series the cross-source pairs and identities need, compares them at the end |
| `src/reva/qa/db_checks.py` | KG aggregate pass (statements grouped by predicate × source × raw object), causal aggregate pass, effect estimates, family edges (part_of / is_a / located_in), object store, causal sanity |
| `src/reva/qa/runner.py`, `report.py`, `cli.py` | orchestration (a check that raises becomes an `error` result, the run continues), JSON (`reva-qa-report/1`) + markdown renderers, `reva qa run` |
| `registry/qa/checks.yaml` | every tolerance and declared rule (pairs, bounded units, count units, identities, projection tables, frequency suffixes, graph families/exclusions, causal wording regex + negation) |
| `tests/unit/test_qa_fixture.py` | fixture mode: 4 atlas tables + KG/causal/effects rows + objects with planted defects (divergent WPP year, share 120 %, negative count, 2030 observation, unflagged projection, forecast-before-availability, estimate_kind "forecast", is_a cycle, dangling object, located_in chain without country, unlicensed raw, missing + corrupt objects, cell citing an unlisted raw, ungraded claim, missing endpoint, H1 disruption axiom, P828 in the KG); each is found exactly; SQL-literal injection refused. 8 tests, ~8 s, no DB/network |

```
uv run reva qa run [--domain cross_source|units|time|graph|licence|provenance|causal ...] \
    [--json out.json] [--md out.md] [--table <regex>] [--verify-all] [--as-of YYYY-MM-DD] [--fail-on fail|warn]
```

Dev DB full run: 327 atlas tables / 107.5 M cells, 4.92 M current KG statements, 61,680 current causal claims,
13.5 k archived objects in **~5.5 min**, peak RSS ≈ 1 GB, no disk written except the reports. No DB write, no flock
needed (read-only). `--verify-all` re-hashes all 4.7 GB of objects (default: seeded sample of 200 objects ≤ 200 MB +
existence of every object).

### Checks per domain (status when issues > 0)

1. **cross_source** — pairs from (a) every pair of series of each headline concept (`registry/atlas/source_order`,
   each series' declared `scale`, `not_equivalent_for` countries excluded), (b) every cross-source pair of a catalog
   concept, (c) declared pairs (ILO vs WDI / Eurostat (annual mean of 12 NSA months) / WEO unemployment; WEO vs WDI
   population; OWID (GCP) vs WDI (EDGAR) CO2). Only calendar-year, numeric, non-projection, iso3 cells. Divergence =
   `|a−b| > abs_tol` and `|a−b|/max(|a|,|b|) > rel_tol`; per pair: overlap, diverging, share, max rel diff,
   **sign flips** (same magnitude, opposite sign), worst countries, both units; examples carry both raw sha256s.
   `warn` when a pair's diverging share exceeds `max_diverging_share`. OECD has no annual current-USD GDP in the atlas
   (only quarterly growth in `oecd.kei_mq`), so "GDP IMF vs WB vs OECD" is IMF vs WB (+ SPC/CBS where present).
2. **units** — bounded shares / indices outside their range (effective unit = catalog concept unit, else provider
   unit; ratio-to-another-aggregate units and gross ratios exempted by declared regexes); negative values in count
   units (generic provider "Number" only when a catalog concept declares it); per-capita × population vs total
   (WDI GDP, WEO GDP, WDI CO2).
3. **time** — non-projection cells starting after today (`fail`), cells whose estimate kind / flag meaning says
   forecast/projection but escape `PROJECTION_SQL` (`fail`), cells starting at/after their own `available_at`
   (`fail`), projection tables with unflagged cells (`fail`), periods not ended / open at publication (`info`), period
   length vs table frequency suffix (`_d/_m/_q/_a`), indicators mixing precisions (`info`), KG statements dated after
   today (declared future-valid predicates excluded).
4. **graph** — dangling objects / subjects by predicate (no `kg.entity` row in the origin), cycles in part_of and
   is_a (family mappings incl. inverse families, P31 excluded; iterative Tarjan), located_in chains (anatomical /
   genomic located_in excluded) that never reach one of the crosswalk country QIDs / `iso3:` nodes.
5. **licence** — atlas tables without a licence (table artifact rights, else atlas source spec — as the API serves
   it), restricted terms (info), pending licence reviews; KG / causal / effects rows whose raw object carries no
   licence.
6. **provenance** — KG / causal / effects rows with no raw object or a raw sha256 without `meta.artifact`; atlas cells
   whose raw sha256 is not in their table's manifest; every archived object present via `store.head`, a seeded sample
   decoded + re-hashed via `store.open`; raw sha256s cited by atlas data without an archived location.
7. **causal** — current claims without a grade for their row (+ stale grades of re-delivered claims), endpoints that
   are not KG entities (by id prefix), self loops, causal-worded / causal Wikidata predicates read as a non-causal
   family, family / link-type labels worded causally (disclaimers such as "an association is not a cause" excluded),
   AUDIT3 H1 disruption axioms without `qualifiers.source_relation`.

## 2. Results on the dev DB (2026-10-17, see `qa_report_latest.md` for counts + examples)

**Clean (population, not sampled):** 0 atlas tables without a licence (327/327); 0 KG statements / causal claims
without a raw object or with an unarchived raw; 0 of 107.5 M atlas cells citing a raw object outside their table
manifest; 0 missing or corrupt objects among 13.5 k (200 re-hashed); 0 forecast cells dated at/after their
availability; 0 unflagged cells in the 7 declared projection tables; 0 period-length mismatches against `_d/_m/_q/_a`
tables (5.9 M cells); 0 part_of cycles (119,874 edges); 0 KG statements dated after today outside the declared
predicates; ILO modelled unemployment = WDI SL.UEM.TOTL.ZS on all 6,531 overlaps; WEO GDP per capita × population =
GDP on all 7,036 overlaps.

**Defects found (new, for owners):**

* **D1 (fail) — 10,804 FAOSTAT `fao.gt` cells with `estimate_kind = "forecast"` ("F", "Forecast value", years 2030 /
  2050) escape `PROJECTION_SQL`**, which knows `projection / unknown_boundary / published_history_boundary_unknown`
  only. They are answered as observations by every observation view. Fix (A-FAO / ATLASOPS): add `forecast` to the
  projection kinds (same list in `reva.evaluation.registry.questions.PROJECTION_KINDS`) or set `projection: true`.
* **D2 (fail) — 4,525 more future-dated non-projection cells**: ILO modelled-estimate projections
  (`ilostat.eap_dwap_*` 2,349, `une_deap_*` 783, `how_temp_*` 261, `sdg_0831_*` 261; flags only say "ILO - Modelled
  Estimates"), OECD Pensions at a Glance projections to 2084 (`oecd.pag` 503: PPEP, OAWAR, LE at 65; flags `{}`),
  **354 `eia_steo.steo_observed` cells for 2026-11…2027-12 whose STEO metadata declares `last_historical_period
  202712`** (a STEO forecast stored as observed), `untc.treaty_status` 7, `who.gho` 6, `imf.er_m` 1.
* **D3 — 30 calendar-2026 `imf.weo` cells + 37 WEO-vintage actuals of fiscal-year economies (BGD, EGY, NPL, PAK, WSM)**
  — the AUDIT3 M7 defect is re-detected automatically (`time.period_not_ended`, `time.period_open_at_publication`).
* **D4 — sign flips between WDI and WEO**: e.g. TKM 1996 real GDP growth WDI **+6.70** vs WEO **−6.7** (verified in
  the archived WDICSV.csv row 372,019: the WDI publishes +6.699991986819853, so the atlas is faithful; the providers
  disagree), IRQ 2024 current account −2.99 vs +2.99 % GDP. 5 exact sign flips in the headline pairs.
* **D5 — WDI GDP per capita × population ≠ GDP for 217 country-years** (e.g. CYP 2017–2019: +43 %); the WDI CO2
  per-capita identity has 0 violations after zero/zero cells are treated as equal.
* **D6 — bounded values out of range**: WDI EG.ELC.RNWX.ZS (renewables excl. hydro, % of electricity production) > 100
  in 453 cells, freshwater withdrawal shares > 100 (31), `wrp.national` religion proportion sum > 1 (42),
  `sscp.frac_v1` fractionalisation > 1 (2); `wb.edstats` UIS.MENF.56 has 942 negative "number" cells.
* **D7 — `doid:has_disease_driver` (61 statements) is read as family `context`**; it is the RO:0007001 relation AUDIT3
  M9 found classified causal by its label word — the KG path reads it as context, the causal path as a cause.
* **Graph**: 121,079 edges point to objects that are not KG entities (`gleif:wikidata_item` 51,183 → QIDs, P31 11,776,
  P2936 9,843, P463 5,161, `unichem:chebi` 3,244, `v4link:classified_as` 2,633 → HS codes; AUDIT3 L7 extended to all
  predicates) and 75,217 statements whose subject is not an entity (mostly `gleif:wikidata_item` LEI subjects); one is_a
  cycle `cl:0000163 ⇄ cl:0000164` (uberon:subclass_of, both directions in the source); 921 located_in subjects never
  reach a country (P17 → historical states such as Q12548 Holy Roman Empire 539, P276 170, P131 145, P706 49).
* **Causal**: 11,435 ungraded current claims (Mondo 9,426, DOID 1,270, Carbon Brief 739 — AUDIT3 M2, still open), 823
  H1 disruption axioms still stored without the source relation, 3,101 endpoints without a KG entity (Mondo → ChEBI
  1,875, Wikidata 800, DOID → OMIM 335), 1 self-loop (Wikidata).
* **Cross-source** (report only): WPP vs WDI population 4.3 % of 13,666 country-years beyond 3 % (CUW, TGO, ISR, GEO,
  SYC — the census-based WDI figures documented in source_order); WDI vs WEO GDP 28 % beyond 5 % (GIN, CAF, UGA, ZWE,
  SUR); current account / growth / inflation 14–30 % beyond 10 % + 0.5 pt; ILO vs WEO unemployment 23 %; OWID (GCP) vs
  WDI (EDGAR) CO2 21 % beyond 10 % (small islands); Gapminder vs HYDE population 20 % beyond 15 %; IPU vs V-Dem
  women in parliament 8 %; WHO vs WDI health series ≤ 1 % (WDI republishes WHO). Every row names both raw objects.
* **Licence**: 16.6 M cells (50 tables) are under restricted terms and must be named with each value (not a defect);
  30 tables (IMF, Reinhart–Rogoff, …) still carry `pending_maintainer_review`; 5 REVA event-study effect estimates
  (`reva.eventstudy`) have no raw object (they are REVA runs; provenance is the run record).

False positives removed while calibrating (all declared in `checks.yaml`, with a comment): gross enrolment / intake /
completion ratios (% of an age group, legitimately > 100), ratios to another aggregate (% of reserves, % of deposits,
old-age dependency), net imports shares, WID net-wealth shares and Gini, WHR dystopia residual, WGI estimates in
WDI's generic "Number", net / LULUCF emissions, scheduled central-bank meetings (`cbcal.meetings`), causal
disclaimers in family descriptions.

## 3. What is missing / owner decisions

1. **Severity policy**: `fail` is used for integrity (missing/corrupt objects, unarchived raws, future or forecast
   cells served as observations); everything else is `warn`/`info`. `--fail-on fail` can gate CI/loaders once D1/D2
   are fixed (today it would fail).
2. **Cross-source tolerances** are first calibrations (3 % population, 5 % GDP, 10 % + 0.5 pt rates); the owner may
   tighten them per concept. Pairs over non-calendar (fiscal-year) cells are not compared yet.
3. The located_in check counts historical countries (Q12548…) as "no country"; a decision is needed whether historical
   polities (`cshapes`/`cow` entities) count as countries.
4. Not covered: KG time-precision mismatches (precision vs value), duplicate-entity detection (identifiers only, never
   names — needs the V4LINK identity rules), per-cell licence of tables reviewed only at table level (AUDIT3 L5).
5. Scheduling: run `reva qa run --json … --md docs/dev/qa_report_latest.md` after each lead final pass (and optionally
   in the worker after atlas snapshots); the report is deterministic for a given DB state except `generated_at`.
